# Personal Portfolio Website

A modern and responsive personal portfolio website built using HTML and Tailwind CSS. This portfolio showcases my projects, skills, and learning journey as a Computer Science student.

## Features

- Responsive design for desktop and mobile devices
- Clean and modern user interface
- Projects showcase section
- Skills section
- Contact information
- Fast and lightweight design
- Built with utility-first Tailwind CSS

## Technologies Used

- HTML5
- Tailwind CSS

## Purpose

This portfolio serves as a central place to showcase my work, projects, and technical skills. It will continue to evolve as I learn new technologies and build more projects.

Portfolio-Website/

## Getting Started

1. Clone the repository.
2. Open `index.html` in your browser.
3. Explore the portfolio.
